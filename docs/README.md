# Diagrams

Three diagrams, each as `.svg` and `.png`. The SVG stays sharp at any size and is the one to use if you are printing; the PNG is easier to paste into Word or PowerPoint.

**`architecture`** — the three tiers and what talks to what. The engine is picked out in ochre and marked *pure — no I/O*, because that is the one box in the system with no dependencies on anything around it. The five collections are colour-coded: blue for the two that are seeded from source files, green for the three that hold user data.

**`engine-pipeline`** — what `generateRoadmap({ role, nodes, profile, now })` does, in seven numbered steps, with what it returns on the right. Step 6 is highlighted because that is where the effort-vs-fixed-time decision is made. The dashed box at the bottom carries real engine output for two different learners against the same target role.

**`er-diagram`** — the five collections, their fields, and their relationships. Read it with the legend in the bottom-left corner: **PK** is a primary key or unique slug, **FK** is a true `ObjectId` reference, **ref** is a lookup by string key, and indented rows are embedded sub-documents rather than separate collections.

The distinction between **FK** and **ref** is the thing worth noticing. Only `roadmaps` and `progress` reference documents by `ObjectId`. Everything to do with the catalog — prerequisites, a role's requirements, the skills on your profile — is linked by string key instead. The reasoning is in the note boxes on the diagram itself.

The diagrams are light even though the app itself is dark. They are read on paper and pasted into a report, where a dark page prints as a solid block of ink. What carries over from the interface is the meaning of the two colours rather than the exact shade: ochre is time you can compress by studying more, blue is time an institution has already fixed for you.

## Regenerating them

`make_diagrams.py` writes all three SVGs. It uses nothing but the Python standard library, so there is nothing to install:

```powershell
cd "C:\Users\ANCEILIN\Desktop\fsd\career-roadmap-generator\docs"
```

```powershell
python make_diagrams.py
```

It prints each file's dimensions as it writes it. The PNGs are separate exports and are not regenerated by the script; if you change a diagram and need the PNG too, open the SVG in a browser and export it, or re-export with any SVG tool.

Two constraints are baked into the script and are worth knowing before editing it, because both cost an afternoon to discover. Arrowheads are drawn as explicit polygons rather than with SVG `<marker>` elements, and all text is horizontal — several renderers, including Word's, silently drop markers and rotated text, which leaves you with unlabelled lines and no error message.
